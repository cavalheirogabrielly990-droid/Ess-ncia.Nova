# Módulo 5 — Aula 1
## Retomar o problema e descobrir por que os dados existem

### Projeto
Essência Nova — Trânsito Inteligente

### Pergunta da aula
Que dados nosso sistema precisa armazenar para resolver o problema escolhido?

### Problema
Dificuldade de encontrar rotas seguras e rápidas e falta de informações sobre problemas no trânsito.

### Pessoa
Motoristas, motociclistas, ciclistas e passageiros.

### Ação
Consultar rotas, registrar ocorrências e receber alertas sobre o trânsito.

### Dado
Localização, rotas, velocidade, ocorrências, condições do trânsito e dados do usuário.

### Resultado esperado
Informar o usuário sobre situações de trânsito, sugerir rotas adequadas e contribuir para uma mobilidade mais segura.

### Cadeia
Problema → Pessoa → Ação → Dado → Resultado

Problemas no trânsito → Motorista → Consulta uma rota → Localização e condições do trânsito → Rota adequada e alerta ao usuário.
