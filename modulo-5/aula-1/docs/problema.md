# Ficha de Retomada — Aula 1

## Projeto
Essência Nova — Trânsito Inteligente

## 1. Problema

O projeto busca solucionar a dificuldade de encontrar rotas seguras e rápidas e a falta de informações sobre problemas no trânsito.

O usuário muitas vezes não possui informações suficientes sobre ocorrências, condições do trânsito e possíveis riscos durante o trajeto.

O Essência Nova reúne essas informações para auxiliar na escolha de rotas e emitir alertas.

## 2. Pessoa

- Motoristas
- Motociclistas
- Ciclistas
- Passageiros
- pedestres

## 3. Ação

- Consultar rotas.
- Registrar ocorrências no trânsito.
- Receber alertas sobre problemas e riscos em tempo real.
- Consultar informações sobre as condições do trânsito.

## 4. Dados necessários

- Dados do usuário.
- Localização.
- Origem e destino.
- Rotas.
- Velocidade.
- Ocorrências de trânsito.
- Condições do trânsito.
- Alertas.
- Contatos de emergência.

## 5. Resultado esperado

Oferecer informações sobre o trânsito, sugerir rotas adequadas e emitir alertas para contribuir com uma mobilidade mais segura e eficiente.

## 6. Cadeia do problema

**Problema → Pessoa → Ação → Dado → Resultado**

Problemas no trânsito → Motorista → Consulta uma rota → Localização e condições do trânsito → Rota adequada e alerta ao usuário.

## 7. Participação das funções

### Backend
Processa os dados do trânsito, aplica as regras do sistema e envia as informações necessárias para o usuário.

### Frontend
Mostra as rotas, informações do trânsito e alertas para o usuário e recebe os dados informados por ele.

### Banco de Dados
Armazena e organiza os dados dos usuários, localização, rotas, velocidade, ocorrências, condições do trânsito, alertas e contatos de emergência.

## 8. Pergunta da aula

**Que dados nosso sistema precisa armazenar para resolver o problema escolhido?**

O sistema precisa armazenar dados dos usuários, localização, rotas, velocidade, ocorrências, condições do trânsito, alertas e contatos de emergência para analisar as situações de trânsito e oferecer informações úteis aos usuários.
